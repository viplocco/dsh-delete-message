# screenshots — README 截图存放目录

`README.md` / `README.en.md` 以相对路径引用本目录下的图片。补图后无需改文档，推送到仓库即自动显示。建议宽度 ≥1200px、PNG 格式，界面为浅色或深色主题均可（与宿主一致即可）。

| 文件名 | 应展示的内容 | 建议拍法 |
| --- | --- | --- |
| `delete-action.png` | 消息操作区特写：悬停任意一条消息，复制按钮右侧出现垃圾桶图标（可带悬停气泡"删除"） | 打开任一会话，鼠标悬停某条消息的操作条后截取该行区域 |
| `confirm-dialog.png` | 删除确认弹窗：标题"删除这条消息？"+ 角色化正文（用户消息与助手回复文案不同，任选其一即可） | 点击某条消息的删除图标，待弹窗完全渲染后截取弹窗区域 |
| `deleted-hidden.png` | 删除生效后的会话视图：被删除的消息行已从转录中消失，其余内容不受影响 | 确认删除后截取同一会话区域，可与第一张对照 |

> 注意：演示截图请使用测试会话或脱敏内容，不要包含真实对话中的敏感信息。
